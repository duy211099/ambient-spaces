# Credits

The only third-party audio is the upright piano sample set listed below
(CC0). All other sound is generated procedurally in the browser
(`assets/js/ambience/audio/procedural.ts`). All artwork is drawn in code.

## Rule for added files

Any audio file added under `priv/static/audio/` must be CC0 (public domain
dedication). Record the source URL and license here in the same commit that
adds the file. Do not add files with attribution or non-commercial terms.
